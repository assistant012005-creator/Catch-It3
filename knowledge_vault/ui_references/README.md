# Визуальная система

- **Neon Cyber**: тёмный #0A0D14, панели #121722, зелёный #00F59B, розовый #FF2A6D, фиолетовый #BD00FF, голубой #05D5FF.
- **Tactical OLED**: чистый чёрный, чёткие границы #262626, моноширинные цифры и янтарные индикаторы без размытия.
- **Glass Metro**: глубокий сине-фиолетовый градиент, полупрозрачные панели, размытие 16px и мягкие капсулы.

Mobile-first: крупные цели нажатия, контрастные состояния, безопасные отступы для нижней панели. Цвет не является единственным носителем смысла. Три вида маршрута используют одно DTO.
