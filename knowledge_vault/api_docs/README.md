# Яндекс Расписания API v3.0

В текущем прототипе сетевого подключения к API нет: используются демонстрационные расписания. Для будущей интеграции: базовый URL `https://api.rasp.yandex.net/v3.0/`, ключ передаётся в `apikey`. Метод `/search/` ищет рейсы между станциями (`from`, `to`, `date`, `transport_types`); `/schedule/` возвращает расписание по станции (`station`, `date`, `event`); `/stations_list/` — справочник станций. Время, часовой пояс, отмены, пагинацию и ограничения тарифа необходимо проверять по актуальной документации Яндекса. Коды станций в соседнем файле приведены по публичным страницам Яндекса; перед интеграцией проверяйте актуальность через API.
